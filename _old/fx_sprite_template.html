Fark — FX Sprite-Sheet Template Maker

Set your frame size and grid, then download a transparent PNG template. Draw one frame of your effect inside each numbered cell (left→right, top→bottom). When you export the finished art, delete the guide layer so the background stays transparent — the game draws each cell over the scene.

Tip: pixel-art effects look best at 32–64 px frames and 8–16 fps. The guide PNG is for tracing; export your final art from the blank sheet (or hide the guide layer in your editor).

How to use this sheet in the game

1. Save your finished sheet (transparent PNG) into an art folder, e.g. Match_Art/fx_burst.png, and add it to the ASSETS list in sw.js so it caches offline.

2. Register the sheet once at load (anywhere after the FX module), using the call shown above.

3. Play it at a screen position (page-space pixels, centered on x/y):

FX.sprite('burst', x, y, {scale:1, fps:12});

To anchor it on a die or element: var r=el.getBoundingClientRect(); FX.sprite('burst', r.left+r.width/2, r.top+r.height/2);

  • Columns auto-detect: if your sheet is a single strip, the game figures out columns from the image width — but passing cols (the 7th arg) is safest when frames wrap onto multiple rows.
  • Frame order is left→right, then top→bottom.
  • loop:true in the sprite opts repeats it; omit for a one-shot.
